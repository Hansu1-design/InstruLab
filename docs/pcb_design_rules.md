# FPGA-TDC PCB设计规则 (基于硬件知识库)

> 来源: EMC 75案例 + 降额规范 + 硬件工程师炼成之路 + 入门小册子
> 针对: tdc_daughterboard 4层板

---

## 一、层叠结构 (已有4层, 确认)

| 层 | 用途 | 关键要求 |
|:--:|------|---------|
| L1 (F.Cu) | 信号+电源 | 走线尽量短, TAC/ADC信号优先 |
| **L2 (In1.Cu)** | **完整地平面** | **禁止走信号线! 必须完整** |
| L3 (In2.Cu) | 电源分割 | VCCINT/VCCO/AVDD各自独立区域 |
| L4 (B.Cu) | 信号 | SPI/低速信号, 可走少量线 |

**最重要的EMC规则**: L2必须是完整地平面, 不开槽、不走线。从EMC案例: 地平面1cm裂缝在100MHz下产生20V压降, 可损坏3.3V逻辑。

---

## 二、布线优先级

### P0: TAC信号路径 (最敏感)

TAC信号从恒流源→充电电容→ADC输入的路径是系统生命线:

```
恒流源输出 → 充电电容(100pF NP0) → ADC输入(AD7980)
```

- **走线长度 < 20mm**, 尽量短
- **两侧包地**, 每5mm加一个GND via
- 远离SPI/时钟等数字信号 > 5mm
- **不要过孔** (通孔引入寄生电感和噪声)
- 使用25mil(0.635mm)宽走线降低电阻

### P1: 100MHz时钟

- 串联22$\Omega$电阻靠近时钟源输出端 (终端匹配, 抑制过冲)
- 走线长度 < 30mm
- 远离板边 > 10mm
- 参考层L2必须是完整地平面 (时钟走线下不可开槽)

### P2: SPI信号 (CS/MOSI/MISO/SCLK)

- **加33$\Omega$串联电阻**, 靠近FPGA引脚端 (抑制振铃)
- 4根线各自包地, 组内间距 > 3倍线宽
- 最多换层1次 (不得已), 换层处加GND via
- 远离TAC路径 > 5mm

### P3: 电源走线

| 电压轨 | 线宽 | 说明 |
|--------|:----:|------|
| 5V输入 | 40mil(1mm) | 承载500mA, 足够 |
| 3.3V_DIG | 30mil(0.76mm) | FPGA IO供电 |
| 3.3V_AVDD | 20mil(0.5mm) | 模拟供电, 磁珠隔离 |
| 1.0V核心 | 40mil(1mm) | FPGA核心供电, 需宽 |

## 三、接口保护电路

### trig_in (外部触发输入)

来自PCB外部, 必须加保护:

```
外部触发 → ESD二极管(NUP2105L) → 100Ω + 100pF低通滤波 → FPGA引脚
```

- ESD二极管靠近连接器放置 (走线 < 5mm到ESD管)
- 滤波电容靠近FPGA引脚

### SPI接口

```
FPGA → 33Ω串联电阻 (靠近源端) → 连接器 → 外部上位机
```

- SPI线长115mm (从J1到U1), 33Ω电阻抑制振铃
- 连接器处可加ESD保护 (可选)

## 四、去耦电容布局

| 位置 | 容值类型 | 数量 | 布局规则 |
|------|---------|:----:|---------|
| FPGA每个电源引脚 | 0.1$\mu$F X7R 0603 | 各1个 | **紧邻引脚** < 2mm |
| FPGA核心 | 10$\mu$F X7R 0805 | 2-3个 | FPGA附近50mm内 |
| ADC供电 | 1$\mu$F NP0 0805 + 0.1$\mu$F X7R | 各1个 | ADC供电引脚< 3mm |
| 电源入口 | 10$\mu$F + 0.1$\mu$F X7R | 各1个 | 连接器入口处 |

**MLCC偏压注意**: X7R在3.3V下实际容量约标称值的50-70%。选型时按2倍降额。

---

## 五、Freerouting布线策略

如果使用Freerouting自动布线:
1. KiCad导出DSN前, 先在PCB中加好过孔(在L1→L2→L1路径上加)
2. 设置布线规则: 线宽0.25mm, 过孔0.5mm/0.3mm
3. 如果Freerouting布不通, 简化: 先手动排TAC路径 + 时钟路径, 剩下的交给Freerouting

---

## 六、投板前检查清单

- [ ] DRC零error (间距+未联网+短路全清)
- [ ] L2层完整地平面 (无信号线、无开槽)
- [ ] TAC路径 < 20mm, 包地
- [ ] 时钟串联22$\Omega$电阻
- [ ] SPI串联33$\Omega$电阻
- [ ] trig_in有ESD保护
- [ ] 去耦电容全部放在对应引脚附近
- [ ] Gerber文件生成, 用kicad-cli验证

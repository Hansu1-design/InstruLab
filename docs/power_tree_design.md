# FPGA-TDC 电源树设计

> 基于硬件知识库审查结果 (2026-07-22)
> 依据: MLCC偏压特性、LDO vs DC-DC决策矩阵、EMC滤波设计

---

## 电源树架构

```
外部输入 (5V / USB / 外部电源)
    │
    ├── DC-DC (降压) → 3.3V 数字
    │    ├── LDO (高PSRR) → 3.3V 模拟 (AVDD)
    │    │    └── 给 TAC + ADC 供电
    │    └── 直接 → FPGA IO bank (VCCO)
    │
    └── LDO (低噪声) → 1.0V~1.2V (VCCINT)
         └── FPGA 核心电压
```

## 电压需求

| 电压轨 | 用途 | 电流需求 | 纹波要求 | 推荐方案 |
|--------|------|---------|---------|---------|
| 3.3V_DIG | FPGA IO + SPI | ~100mA | <50mVpp | 直接DC-DC输出 |
| 3.3V_AVDD | TAC + ADC模拟 | ~30mA | <5mVpp | DC-DC→LDO(PSRR>60dB) |
| 1.0V~1.2V | FPGA核心 | ~200mA | <30mVpp | 独立LDO |

## 去耦电容选型

### MLCC DC偏压注意事项
- X7R在3.3V下实际容量约为标称值的50-70%
- NP0/C0G无偏压衰减, 优先用于模拟供电
- 必须在原理图中标注降额后的实际容值

### 推荐去耦方案

| 位置 | 容值 | 类型 | 耐压 | 数量 | 布局要求 |
|------|------|------|------|:----:|---------|
| FPGA核心 | 10μF | X7R, 0805 | 6.3V | 2-3 | 靠近FPGA电源引脚 |
| FPGA核心 | 0.1μF | X7R, 0603 | 6.3V | 每个引脚1个 | 紧邻引脚 |
| ADC模拟 | 1μF | NP0, 0805 | 10V | 1 | ADC供电引脚 |
| ADC模拟 | 0.1μF | NP0, 0603 | 10V | 1 | 紧邻ADC |
| IO供电 | 4.7μF | X7R, 0805 | 10V | 2 | FPGA IO bank附近 |
| 输入滤波 | 10μF+0.1μF | X7R | 16V | 各1 | 电源入口 |

## EMC滤波

- 电源入口: 共模扼流圈 + π型滤波 (C-L-C)
- ADC模拟电源: 磁珠 + 电容滤波 (Bead-C)
- 地平面: 4层板, L2整层地, 不开槽

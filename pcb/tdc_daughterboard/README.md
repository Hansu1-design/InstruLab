# TDC Daughterboard 使用说明

## 打开项目
1. 双击桌面 KiCad 10.0 图标
2. 文件 → 打开 → 选择 tdc_daughterboard.kicad_pro

## 查看/修改原理图
3. 点击"原理图编辑器" → 查看完整电路
4. 如需添加器件: 放置 → 符号 → 从库选择

## PCB布局布线
5. 点击"PCB编辑器" → 查看当前布局
6. 布线规则: 模拟信号0.3mm, 电源0.5mm, GND尽量宽
7. 关键注意事项:
   - C1(100pF)紧贴AD7980 IN+引脚
   - 模拟GND和数字GND在AD7980下方单点连接
   - REF5050远离开关电源区域

## 生成Gerber(发板打样)
8. 文件 → 制造输出 → Gerber文件
9. 选择所有层, 输出到 gerber/ 目录
10. 文件 → 制造输出 → 钻孔文件
11. 打包所有文件 → 发给PCB厂商

## 板卡参数
- 尺寸: 50 x 40 mm
- 层数: 4 (Top/GND/PWR/Bottom)
- 厚度: 1.6mm
- 铜厚: 1oz
- 最小线宽/间距: 0.2mm/0.2mm
- BOM成本: ~$20 (不含PCB打样费)

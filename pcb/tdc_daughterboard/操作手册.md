# TDC子板 — 自动布线 + 打样操作手册

## 环境
- KiCad 10.0 ✅ (已装)
- Freerouting v2.2.4 ✅ (已装, 桌面有图标)
- PCB文件: `pcb/tdc_daughterboard/tdc_daughterboard.kicad_pro`

---

## 第一步：KiCad导出DSN

```
1. 双击打开 tdc_daughterboard.kicad_pro
2. 双击 tdc_daughterboard.kicad_pcb → 进入PCB编辑器
3. 调整元件布局(可选):
   - 左键拖元件到合适位置
   - 按 M 键移动, R 键旋转
   - 布局参考: 左上J2(SMA)→右侧R1/C1→下方U1(ADC)→右下U2(基准)→左J1(排针)
4. 文件 → 导出 → Specctra DSN
   → 保存到: pcb/tdc_daughterboard/tdc_daughterboard.dsn
```

## 第二步：Freerouting自动布线

```
1. 双击桌面 Freerouting 图标
2. 文件 → 打开 → 选 tdc_daughterboard.dsn
3. 布线参数:
   - 走线宽度: 0.3mm (信号) / 0.5mm (电源)
   - 过孔: 0.6mm/0.3mm
   - 层数: 2层 (F.Cu / B.Cu)
4. 点击「自动布线」按钮
   → 等几秒, 布线完成
5. 文件 → 导出 → Specctra SES
   → 保存到: pcb/tdc_daughterboard/tdc_daughterboard.ses
```

## 第三步：KiCad导入布线

```
1. KiCad PCB编辑器 → 文件 → 导入 → Specctra SES
   → 选 tdc_daughterboard.ses
2. 布线完成后:
   - 检查 → 设计规则检查(DRC)
   - 看有没有未连接的线
3. 调整丝印标注:
   - 元件标号(如 R1, C1) 移到合适位置
   - 调整文字大小: 双击文字 → 编辑 → 大小1.0mm
```

## 第四步：出Gerber发嘉立创

```
1. 文件 → 制造输出 → Gerber文件
   - 选择所有层
   - 输出到: pcb/tdc_daughterboard/gerber_final/
   - 确定

2. 文件 → 制造输出 → 钻孔文件
   - 输出到同一目录

3. 打开 gerber_final/ 目录
   - 所有 .gbr/.drl 文件打包成 ZIP
   - 上传嘉立创下单助手即可打样
```

## PCB参数(发给板厂)

```
- 板子尺寸: 50 x 40 mm
- 层数: 2层 (双面板)
- 板厚: 1.6mm
- 铜厚: 1oz
- 表面处理: HASL (喷锡)
- 最小线宽/间距: 0.2mm/0.2mm
- 最小过孔: 0.3mm
- 数量: 5-10片
- 预计价格: ~¥20-50 (嘉立创打样)
```

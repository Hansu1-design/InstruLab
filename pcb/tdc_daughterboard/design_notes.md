## 核心架构

### 粗测+细测双级 TDC（赵雪鹏TDC论文 ★★★）

```
外触发 → 时间分割逻辑(6DFF) → 粗测(t₁₂) → 49bit计数器@400MHz
                              ├─ 细测(t₁) → TAC(恒流源10mA+100pF)→16bit ADC
                              └─ 细测(t₂) → TAC(恒流源10mA+100pF)→16bit ADC
```

| 参数 | 目标值 | 条件 |
|------|-------|------|
| 分辨率 | 1.5 ps | 理论最佳(TAC+16bit ADC) |
| 测量精度RMS | <60 ps | 10ms量程内(TAC+恒流源) |
| 量程 | 391 小时 | 49bit粗计数器极限 |
| 最优量程 | <10 ms | 精度最优区间 |

### 可选 CARRY4 全数字细测量（梁东飞论文 ★★★）

替代TAC路径，纯FPGA内实现：
- 76级CARRY4进位链（33ps/级，覆盖~2.5ns）
- 3路并行TDC取中值抗噪
- 系统抖动19.3 ps（经C验证）
- MAX5719 20bit DAC补偿

## 关键电路参数

### TAC 模拟部分
- 恒流源: 10mA (±0.1% 精度，低温漂型)
- 充电电容: 100pF NP0/C0G（零温漂）
- ADC: AD7980 16bit 1MSPS SPI接口
- Vref: 5.0V 精密基准源

### 时钟方案（三阶锁相环 ★★★）
- 板载晶振: 100MHz TCXO（±0.1ppm）
- PLL: 三阶锁相环频率合成器
- VCO输出: 400MHz（可调范围±12.5%）
- 环路带宽: 100kHz

### 电源方案（四相交错Buck ★★☆）
- 5V输入 → 3.3V数字 (DC-DC降压)
- 5V输入 → 3.3V模拟 (DC-DC + LDO高PSRR)
- 5V输入 → 1.0V核心 (LDO)
- 电源纹波 <5mVpp（模拟轨）

### 温度补偿（Pt1000比例法 ★★★）
- 传感器: Pt1000（0~65℃精度0.03℃）
- 测温方法: 三点delta法
- 补偿周期: 开机自校准 + 每10分钟温度采样

## 设计检查

- [ ] TAC路径走线 < 20mm, 包地
- [ ] 模拟地与数字地单点桥接
- [ ] ADC供电近端去耦（1μF NP0 + 0.1μF）
- [ ] 时钟源近端放置，远离数字区
- [ ] FPGA核心电压去耦（每引脚1×0.1μF + 2×10μF全局）
- [ ] ESD保护输入端口
- [ ] 4层板：L2完整地平面
